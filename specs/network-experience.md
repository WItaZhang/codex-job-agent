# 联网操作经历与准入（实验）

## 范围与最小计划

先合成测试，再实现 SQLite 准入与报告，接入招聘板 HTTP、apply/form-fill 共用执行入口，最后独立只读审阅及四项验证。不依赖其他实验。默认启用，无静默关闭开关。未覆盖 vendor 批量抓取暂拒绝执行并解释原因，避免默认流程继续无界重试。

## 契约

- 每次受控逻辑尝试先以 BEGIN IMMEDIATE 原子登记，同风险范围只允许一个在途操作。attempt UUID 同时作为 correlation/run 标识；没有安全账号身份，账号记 unknown，不猜用户。不同操作共享站点风险。已知 ATS 按确定性租户路由隔离；未知 host 以整个 host 为范围。
- 不存原始 URL、query、fragment、用户名密码、路径、网页正文、异常文本或表单字段。资源用去 query/fragment 后路径摘要，租户摘要；仅存主机、固定结果枚举、时刻与计数。新数据库在本地忽略目录；历史保留30天，安全暂停状态不随历史清理消失。
- 暂时错误指数退避，累计3次则需要本人核实；429 尊重 Retry-After 秒数/HTTP日期，缺失用默认冷却；403为 unknown，不声称封号。验证码、登录、明确锁定立即人工暂停。unknown 也暂停。成功不清零累计失败，避免分页/详情部分成功掩盖反复失败；只有有证据的人工恢复清零。
- 在途租约到期记 interrupted，人工核实，不自动抢占或重试。重复同一结果幂等，冲突结果拒绝。完成后暂停不能靠时间、换 URL、换会话解除。
- 恢复只能经显式人工证据登记，绑定当前暂停 attempt 与证据种类（本人报告已解决/已核实未执行），保存证据摘要而非正文。这是宿主可信声明而非身份认证；离线复盘没有恢复能力，不自动探测网站。已有授权不重问；没有真实证据维持暂停。
- 用户可见错误/报告列站点、次数、时间、原因、恢复条件与来源 attempt。复盘确定性聚合失败、验证码与恢复后成功，置信边界为受控入口观察；无模型也可用。

## 验收样例

重复暂时失败跨实例暂停；CAPTCHA/锁定立即暂停；429冷却内零调用；同站多URL累计及租户隔离；并发互斥、崩溃、幂等；fetch与apply事件接线；脱敏、恶意文本不成为规则；报告不解除暂停；fake执行不提交。具体覆盖缺口与运行方式见 docs/network-experience.md。
