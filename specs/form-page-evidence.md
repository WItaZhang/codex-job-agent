# 表单读回与进度证据修复

本片只修已证实的既有填表阻塞，不开启 2b/2c，不操作真实申请，不改变业务答案、提交边界或工具权限。开发依据业务会话提供的匿名结构统计和合成页面，不读取私人截图、日志、profile.json 或 .env。

1. 原生 radio 位于 role=radiogroup 内时，读取每个选项，再按组汇总；组容器与子控件不能同时被跳过。保留 label[for]、aria-labelledby、required、选中值及隐藏原生控件的现有处理；纯 ARIA radio 仍只读一次。
2. 截图只因实际渲染的联系方式及按栏目匹配的 contact 字段遮黑。普通 DOM 中 script/style/template、display:none 或 visibility:hidden 的后代文本不能使可见祖先整块遮黑。可见的联系方式继续遮黑，密码值永不读取，可见的密码框提示文字照常保护；无法可靠遮盖时仍不保存截图。隐藏内容不算已在真实网站证实的触发原因，本片验证其通用复现；不放宽脱敏规则或读取真实截图推测原因。无法精确定位的 shadow 内容仍保守遮住宿主，不宣称完全消除过度遮挡。
3. 当前明确步骤（aria-current=step）变化时，即使 URL 和残留字段相同也算换页；保存步骤来源供恢复后判定。没有明确步骤时，题目集合互相包含仍按追问处理；仅有相同标题和少量共同栏不再足以合并两页。真正同页连续 filled 三次仍停止；前进/返回另页重置计数，字段编号及旧录制兼容保留。
4. 原页接续检查用稳定 reason_code 区分标签页丢失、地址歧义、站点变化及浏览器身份不可验证。重复地址继续拒绝；不通过新开页、关闭旧页或放宽绑定解除限制。返回不带私人页面内容或异常中的路径/参数。

最小计划：先用上述结构写失败测试，再修通用提取、可见内容收集、页标识和诊断；用临时浏览器验证不重复读取、隐私遮盖和换页计数，再完整回归、合并推送。真实网站效果仍由授权业务会话验证，不能把合成通过称为真实申请完成。
